All your AI quotas, usage limits and costs in one place.

A free, open-source monitor that shows how much of your 5-hour window, weekly quota or monthly budget is left, across the AI assistants and APIs you use. A desktop app and a terminal dashboard, and it only ever reads.

What it is

Know what is left before a limit stops you

If you work with several AI assistants and APIs, you probably hop between dashboards to find out how much is left. Cuotai puts it all in one place and keeps it fresh in the background.

It is made for developers, teams and heavy users of coding assistants and AI APIs who juggle more than one subscription or key. A Rust core does the reading; a Tauri desktop app and a Ratatui terminal dashboard present it.

The name comes from cuota, how many Portuguese speakers say “quota”, plus AI. The four-color C is a gauge that is never quite closed, the same ring that shows how much quota an account has left.

Bars show what is left, not what was used. The band on a bar marks a steady pace until the reset, as a linear estimate.

What you get

  • Every limit in one window One card per account with its windows, rate limits, balances and spend, each with its reset time.
  • Pace and “runs out” warnings Whether what you used so far lasts until the reset, or when it runs out if it does not. A linear estimate, not a promise.
  • Alerts that matter Optional system notifications for resets, thresholds you choose and exhausted quotas, with quiet hours. Nothing is sent to anyone.
  • Which account has room Put interchangeable accounts in a group and Cuotai marks the best one, as advice only. It never switches accounts for you.
  • Paid extra usage When a plan bills past its limit, the spend so far is shown apart from the plan limits. Cuotai never changes billing settings.
  • History and local cost Charts of how each quota moved, kept on your computer, and an optional cost estimate from your own Claude Code, Codex CLI and Gemini CLI logs.
  • Runs where you work Windows, macOS and Linux, with a tray or menu-bar popover for a quick look.
  • Scriptable cuotai --json, an opt-in read-only local server, events and hooks with --watch, and executable extensions.
  • Yours to shape Built-in themes in dark and light, your own themes, and a translated interface.

What to expect

  • Read-only

    Cuotai asks providers for quota, usage and billing numbers. It never sends a request that spends credits, and it never changes a provider's billing settings.

  • Credentials stay out of the config

    Sign-ins and tokens are kept in your system's vault: macOS Keychain, Windows Credential Manager or Linux Secret Service. The settings file holds references or the names of environment variables, never a secret.

  • Some interfaces are undocumented

    Several providers expose usage only through internal interfaces the vendor does not document. These may change without notice; when one stops matching, the card says so.

  • Some reads cost money

    AWS Cost Explorer charges per request, so it is read once an hour by default and never more than every 15 minutes. Google Cloud Monitoring can also bill for reads.

  • A web session is a full login

    A few providers are read through a web session you paste. It stays in the vault and goes only to that provider's hosts over HTTPS, but the provider's terms may not allow third-party tools. Read the risks first.

  • Nothing in the middle

    There is no Cuotai account or cloud service. The update check is optional and sends only the version, system and architecture. Reading the providers' public status pages is off by default.

Every integration is classified as Official, Undocumented, Derived or Unavailable in the usage access matrix, with the evidence for each. Services with no usage query are not offered when you add an account.

Install

Pick the app, the terminal version, or both

Direct downloads are on the latest release. Each release's notes say which of its files are signed.

Desktop app

macOS Apple silicon and Intel

brew tap jmarcon/cuotai
brew trust jmarcon/cuotai
brew install --cask jmarcon/cuotai/cuotai-app

Or download the .dmg from the latest release. A build that is not notarized needs one extra step the first time.

Windows x64

Download the .exe or .msi installer from the latest release. An installer that is not code-signed triggers a SmartScreen warning: what to do.

Linux x64

Download the .deb, .rpm or .AppImage from the latest release. On GNOME, the tray icon needs the AppIndicator extension.

Terminal version

Homebrew macOS and Linux

brew tap jmarcon/cuotai
brew trust jmarcon/cuotai
brew install jmarcon/cuotai/cuotai

Scoop Windows

scoop bucket add cuotai https://github.com/jmarcon/scoop-cuotai
scoop install cuotai

Direct download

Terminal archives for each system are on the latest release.

From the repository needs Rust

cargo install --git https://github.com/jmarcon/cuotai cuotai-tui --locked

Every release ships a signed SHA256SUMS and build provenance, so you can verify your download. Uninstalling removes the app only; your accounts file, history and vault entries stay until you delete them. Channel status, and how each one was checked, is in the install guide. To build it yourself, see building from source.

How to help

A one-person project, and help counts

Support happens on GitHub. Never paste a real key, token or cookie into an issue.

  • Star the repository so more people find it.
  • Report a bug or a provider problem, or ask for a new provider.
  • Ask a question or share a setup in Discussions.
  • Translate or proofread a language. Some are machine drafts, so a native speaker's review is the most useful help.
  • Contribute a theme, a fix or a provider.
  • Report a security problem privately, never in a public issue.
