# Privacy and data inventory

Cuotai is a read-only monitor that runs on your computer. It has no telemetry, no account of its own and no server of its own: it sends nothing to its authors. This page lists every network flow Cuotai can start and every file, directory and credential-vault entry it keeps, with how to erase them. The tables are generated from the core's typed manifest (`cuotai_core::privacy`, PRD 0052 RF4), and a test fails when they drift from it.

- **Network:** each row is one purpose. Requests go only to the hosts in the row and only when its trigger happens; "off" means nothing is sent until you turn the feature on. Extensions and hooks run programs you approved yourself, which may use your network independently of Cuotai.
- **Local data:** `<local data>/cuotai/` stands for every data folder in use or left behind: `CUOTAI_DATA_DIR`, the desktop's data-folder choice and the OS default (`<local data>` is the OS local data directory: `~/Library/Application Support` on macOS, `%LOCALAPPDATA%` on Windows, `~/.local/share` on Linux); an erase clears each one Cuotai created and keeps the others. `<config>` is the OS configuration directory (`~/Library/Application Support`, `%APPDATA%`, `~/.config`). Cuotai keeps credentials only in the OS credential vault (services `cuotai.oauth` and `cuotai.serve`) or reads them from the environment variables your accounts name; no file below holds a secret except the optional `serve/token`.
- **Device check:** with your consent, the Add-account picker asks only whether known tools' folders exist, never opening them; the [device-check table](providers.md#device-check-presence-only) lists every path it looks for.
- **Listener check:** before a 9router password or session goes to an instance on this computer over plain HTTP, Cuotai reads the operating system's own socket table to see who listens on that port (on Linux `/proc/net/tcp` and `/proc/net/tcp6`, on Windows the TCP table and the owning process's user, on macOS the open sockets of your own processes). It runs locally: nothing is sent, logged beyond the verdict, or stored ([details](providers.md#9router-nine_router)).
- **Logs:** the app log is redacted before it is written (see [App log](advanced.md#app-log)); it never holds a token, cookie, body, URL path or query, or e-mail address.
- **Typed secrets:** a key or session you type in the desktop's account dialog is wiped from Cuotai's own memory when the dialog's request ends; the copies held by the dialog's web view and by the request that carried it to Cuotai are outside Cuotai's reach and cannot be wiped.
