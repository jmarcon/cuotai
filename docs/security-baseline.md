# Security baseline

The security properties Cuotai promises, each tied to the test that fails when the property regresses (PRD 0050 RF7). `cargo xtask security-baseline` reads this table: every row needs at least one test carrying its marker comment (`security-invariant: SEC-…`), every marker in the code needs a row here, every `file::test` owner must name a test that exists, and every row declares the platforms its tests run on. The same command checks the desktop Content Security Policy and HTML pages (RF1.4), the pinned release-critical values of `tauri.conf.json` (`SEC-RELEASE-PINS`) and that product code builds HTTP clients only through `network::builder` (RF7.2); `apps/desktop/tools/ui-shots/csp-smoke.mjs` loads the three pages under that policy in headless Chrome (RF1.4).

Platforms are the CI runners the owning test runs on. A Unix-only test (`#[cfg(unix)]`) lists Linux and macOS, a Windows-only test (`#[cfg(windows)]`) lists Windows. Windows file-permission checks follow PRD 0050 §13 option A, narrowed: a DACL is refused when it grants a broad principal (Everyone, Authenticated Users, Users, Guests, Anonymous, INTERACTIVE, NETWORK) access, when it is NULL or when it cannot be read; the default profile ACL (the owner, SYSTEM and Administrators) is accepted, and other individual users or groups are not judged.

## Recorded exceptions

- **`withGlobalTauri: true` (PRD 0050 RF1.3).** The desktop UI is a set of unbundled ES modules with no package build, and they call `window.__TAURI__.core.invoke` and the event API directly. The global stays until every direct use moves to an official module bridge (not `__TAURI_INTERNALS__`). The CSP above is what keeps a foreign script from reaching that global.
- **The desktop updater's own client (PRD 0018).** `tauri-plugin-updater` builds its HTTP client inside the plugin, with its own `rustls-tls` roots and redirect handling, and verifies the minisign signature of every artifact it downloads. It carries no credential. The client-builder source check covers Cuotai's own code only (`CLIENT_BUILDER_ALLOW` in `xtask/src/security.rs` holds the core seam, `crates/cuotai-core/src/network.rs`, and nothing else).
- **`connect-src 'self'`.** The UI reads its bundled catalogs (`locales/*.json`) with `fetch` from the app's own origin. `'self'` is the application bundle, never a network host.
- **`style-src 'unsafe-inline'`.** Components write `style` attributes for bar positions and sizes, and user themes are inserted as style elements. CSP still blocks every remote, `data:` and `blob:` fetch a style could trigger (`img-src` and `font-src` are `'self'`).
